Professional Experience

QA Engineer

SoftKraft
August 2021 – Present

As a QA Engineer at SoftKraft, I worked in a fast-paced, R&D-driven environment with minimal documentation and rapidly evolving requirements. I contributed across multiple stages of the development lifecycle—from requirement clarification and test design to automation, CI/CD integration, and release validation.

Key Responsibilities & Achievements:

  • Test Automation & CI/CD Integration: Developed and maintained end-to-end automated test suites using TypeScript and Playwright, integrated into GitHub Actions pipelines. This significantly reduced manual regression cycles and improved deployment confidence.
  • API & Backend Validation: Validated RESTful APIs using Postman and Swagger, ensuring seamless and reliable data exchange across services. Verified data consistency by directly querying PostgreSQL databases.
  • Cross-browser Testing: Performed both manual and automated UI tests using BrowserStack, ensuring consistent behavior across browsers and platforms.
  • Collaboration & Issue Management: Worked closely with developers, product owners, and designers in tools such as Figma, Slack, and GitHub to triage, reproduce, and resolve bugs based on internal QA findings and client-reported issues.
  • Test Documentation & Reporting: Created, maintained, and executed test plans and test cases in TestRail, providing real-time traceability and clear visibility of test coverage and results to stakeholders.
  • Security, Performance & Integration Testing: Supported performance testing and basic security testing efforts as part of release validation cycles. Helped optimize test strategies for large-scale document management systems deployed on AWS ECS.
